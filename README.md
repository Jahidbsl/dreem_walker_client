# ⚡ Dreem Walker - Client Side

A modern, high-performance frontend web application built with **Next.js**, designed to consume the Laravel REST API backed by PostgreSQL, featuring secure token-based authentication (Laravel Sanctum).

[![Next.js](https://img.shields.io/badge/Next.js-black?style=for-the-badge&logo=next.js&logoColor=white)](https://nextjs.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)](https://tailwindcss.com/)
[![Vercel](https://img.shields.io/badge/Vercel-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://vercel.com/)

---

## 🛠️ Tech Stack & Features

- **Framework:** Next.js (React)
- **Styling:** Tailwind CSS
- **Authentication:** Token-based authentication consuming Laravel Sanctum API
- **Deployment:** Vercel
